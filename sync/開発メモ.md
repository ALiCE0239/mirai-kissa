# 未来喫茶 — アプリ反映用 開発メモ

Web で決めた内容を、アプリ版 Cursor チャットに渡すためのメモです。  
**追記したら** `python3 tools/sync-with-app.py push` でアプリの `docs/Web同期/` にコピーされます。

---

## 使い方

1. 下の「未反映・進行中」に箇条書きで書く（日付・機能名・UI/計算/データの別）
2. 必要なら `sync/機能対応表.json` の `status` も更新
3. ターミナルで `python3 tools/sync-with-app.py push`
4. **アプリ側 Cursor** で「`docs/Web同期/開発メモ.md` を読んで実装して」と依頼

  - 無料枠対策: Firestore `eventReports/{uid}_{archiveId}`（1アーカイブ1件・1ユーザー最大10件はクライアント側）。Storage 追加なし（バナースクショは既存の公開URLを参照）。下書きは本人のみ閲覧。
  - 実装: `js/guides.js`、`index.html`（`tmpl-guides-report` / `tmpl-mypage-event-report`）、`js/app.js`、`js/event-support.js`（アーカイブから導線）、`css/style.css`。ルールは `eventReports` を追加。インデックスは `isPublished+updatedAtMs` と `authorUid+updatedAtMs`。
  - アプリ側: 今回は Web の攻略図書館投稿。アプリのイベラン記録から同等レポートを出す場合は別途。
- 2026-08-17 — 【新機能】イベラン支援アーカイブ（Web、要ログイン）を追加。マイページ →「イベラン支援」から利用。
  - 概要: 1ユーザー最大3件のイベントを保管。イベント中に自分のPt（＋任意で目標順位ボーダーPt）を時刻付きで記録し、自作SVGグラフで推移を表示。着地予想と目標到達までの残り周回/クリスタル/時間を提案。イベント終了時にバナーページのスクショを1枚保存できる。
  - 無料枠対策: アプリのような無制限保存は避け、Firestore は `users/{uid}/eventArchives/{archiveId}`（最大3件・件数制限はクライアント側で担保）、Storage はバナー画像1枚のみ `users/{uid}/eventArchives/{archiveId}.jpg`（Canvasで1280px/JPEG圧縮）。
  - 計算は新規式なし。`PjskEngine.estimateBorderTargetPt`（過去平均で目標Pt推定）/ `envyEventPtBase`＋`lbEventPtMul`（1周Pt）/ `ENVY_RUNS_PER_HOUR`（28周/時）を再利用。ペースは記録ログの差分から算出。
  - 2026-08-17 追記【最終着地予想からの詳細周回プラン】: 目標Ptの決定を「手入力 > ボーダー最終着地予想（記録したボーダーPtの推移をイベント終了時刻へ外挿・`getBorderProjection`）> 過去平均」の優先度に変更。イベラン診断が上位ボーダー（過去平均）を参照する箇所を、実データ外挿の最終着地予想に置き換える意図。編成（総合力/実効値/イベントボーナス、任意で所持クリスタル）を入力済みなら、残りPt＝目標−現在Pt・残り時間・クリスタルから `diagnosisFeasiblePlan`／`diagnosisCapPlan`／`diagnosisRankFromMargin` を再利用して 5/10炊きの最適配分・必要時間・必要クリスタル・到達判定(S〜D)を表示。所持クリスタル未指定時は時間のみで算出（実質無制限扱い）。
- 2026-08-18 追記【公開ページのイベントアーカイブ・本実装】: セカイノート（`#/p/:id`）に `isPublic == true` のアーカイブ（バナースクショ・最終順位/Pt・グラフ）を表示。イベント設定の「公開ページに表示する」で制御。未設定ドキュメントは本人ハブ表示時に `isPublic: true` を補完。公開一覧は `where('isPublic','==',true)`。ルールは本人常時 read/write、公開 read は isPublic。イベランレポート投稿は見送り。
