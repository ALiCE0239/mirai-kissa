# 未来喫茶 — アプリ反映用 開発メモ

Web で決めた内容を、アプリ版 Cursor チャットに渡すためのメモです。  
**追記したら** `python3 tools/sync-with-app.py push` でアプリの `docs/Web同期/` にコピーされます。

---

## 使い方

1. 下の「未反映・進行中」に箇条書きで書く（日付・機能名・UI/計算/データの別）
2. 必要なら `sync/機能対応表.json` の `status` も更新
3. ターミナルで `python3 tools/sync-with-app.py push`
4. **アプリ側 Cursor** で「`docs/Web同期/開発メモ.md` を読んで実装して」と依頼
