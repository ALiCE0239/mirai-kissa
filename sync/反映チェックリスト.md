# Web 変更 → アプリ反映チェックリスト

Web（未来喫茶）で機能・UI を変えたとき、アプリ版でも統一するための手順です。

## 1. Web で作業したあと（このリポジトリ）

- [ ] `data/計算式.txt` に式・仕様を追記した
- [ ] `sync/開発メモ.md` の「未反映・進行中」に要点を書いた
- [ ] `sync/機能対応表.json` の該当 `status` を更新した（必要なら）
- [ ] `python3 tools/sync-with-app.py push` を実行した
- [ ] Web 公開する場合は `git push`（GitHub Pages）

## 2. アプリ側 Cursor で

- [ ] `docs/Web同期/開発メモ.md` を開いて依頼文に含める
- [ ] `docs/Web同期/機能対応表.json` で未実装機能を確認
- [ ] 計算変更 → `PjskEngine.swift` + 該当 View（`Fmt.swift` 等）
- [ ] UI 変更 → `MiraiKissaTheme.swift` + `MiraiAppUI.swift`
- [ ] 新計算機 → `CalculatorTool` に case 追加
- [ ] Xcode でビルド確認

## 3. 変更の種類別クイック参照

| 変更内容 | Web | アプリ |
|----------|-----|--------|
| 倍率だけ | `data/炊き数倍率.txt` → push | 自動コピーで反映 |
| 計算式 | `pjsk-engine.js` + 計算式.txt | `PjskEngine.swift` 手動 |
| 新画面 | `index.html` tmpl + `calculators.js` | 新 View + ナビ |
| 色・カード | `style.css` | `MiraiKissaTheme.swift` |
| 楽曲リスト | `楽曲基礎点.txt` → push | Remote Config 更新（別途） |

## 4. アプリ Cursor への依頼例

```
docs/Web同期/開発メモ.md と docs/Web同期/機能対応表.json を読んで、
Web版のポイント調整NEXT（#/adjust-next）をアプリに実装してください。
計算は docs/計算式-Web同期.txt と PjskEngine.swift に合わせてください。
UI は MiraiAppUI.swift の CalculatorTool パターンに揃えてください。
```
