未来喫茶 — 倍率データの編集方法
================================

■ 編集するファイル
  data/炊き数倍率.txt

■ 手順
  1. テキストエディタで「炊き数倍率.txt」を開く
  2. [イベントP] と [報酬] の数値を書き換える（キズナは自動計算のため編集不要）
  3. ファイルを保存する
  4. ブラウザで未来喫茶のページを強制再読み込み（Mac: Cmd+Shift+R）

■ 記入例
  [イベントP]
  5=23        ← 5炊きのときイベントPは0炊きの23倍

  [報酬]
  10=25       ← 10炊きのとき報酬は0炊きの25倍

  ※ キズナは 0炊き=150 EXP、N炊き=150×[報酬]の倍率 で自動計算されます。

■ 注意
  - ローカルで index.html を直接開く（file://）と読み込めない場合があります。
    そのときはターミナルでプロジェクトフォルダに移動し:
      python3 -m http.server 8080
    ブラウザで http://localhost:8080 を開いてください。
  - 読み込みに失敗した場合、サイトは内蔵のデフォルト値で動作します。
    開発者ツール（F12）のコンソールに警告が出ます。

■ 各計算機での使われ方
  - あまつゆ計算機（ライブ周回）→ [報酬]
  - イベントPt計算（LB選択の参考）→ [イベントP]
  - ポイント調整 → [イベントP]
  - キズナ計算 → 150 × [報酬] の倍率（ファイル編集不要）
  - イベラン診断 → js/border-rankings-data.js（コード内蔵・HTTP不要）

■ ボーダーデータの更新（イベラン診断）
  Excel シートで編集 → スクリプトで再生成する方式です。

  1. 現行データを Excel 化（初回・最新化したいとき）
       PYTHONPATH=./.pylibs python3 tools/export-border-xlsx.py
       → data/イベントボーダー一覧.xlsx を出力
  2. data/イベントボーダー一覧.xlsx の「イベント別」シートを編集
       - 1イベント＝1行。T10 / T50 / T100 / T500 / T1000 / T5000 列にボーダーPtを入力
       - その順位帯のデータが無ければ空欄でOK（詰めなくてよい）
       - バナー / ユニット / 種別 / 日数 / ボーナスも各行に入力
  3. Excel から本番データを再生成
       PYTHONPATH=./.pylibs python3 tools/import-border-xlsx.py
       → js/border-rankings-data.js を再生成
  4. ブラウザで未来喫茶を強制再読み込み（Cmd+Shift+R）→ git commit / push

  ※ 表示用の「約○億○万P」はポイントから自動生成されます（手入力不要）。
