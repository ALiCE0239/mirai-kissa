未来喫茶 — プロセカアプリ（iOS）との同期
========================================

■ アプリの場所
  /Users/alice/Desktop/プロセカアプリのコピー/プロセカアプリ

■ 方針
  Web の UI・機能をアプリでも統一していく。
  アプリ独自機能（プロフィール・リザルト・Firebase 等）はそのまま拡張。

■ いちばん大事な3ステップ

  1. Web で直した内容を sync/開発メモ.md に書く
  2. python3 tools/sync-with-app.py push
  3. アプリ版 Cursor で docs/Web同期/ を読んで実装

■ コマンド（未来喫茶フォルダ）

  python3 tools/sync-with-app.py push     … データ + sync/メモ一式 → アプリ
  python3 tools/sync-with-app.py pull      … 逆方向
  python3 tools/sync-with-app.py diff      … 差分
  python3 tools/sync-with-app.py status    … 機能の対応状況一覧

■ アプリにコピーされるもの

  データ:
    data/炊き数倍率.txt → プロセカアプリ/炊き数倍率.txt
    data/計算式.txt     → docs/計算式-Web同期.txt
    data/楽曲基礎点.*   → docs/楽曲基礎点-Web同期.*

  メモ・仕様（sync/ フォルダ丸ごと）:
    → docs/Web同期/
      開発メモ.md
      機能対応表.json
      UIデザイン仕様.md
      反映チェックリスト.md
      Cursorアプリ用プロンプト例.txt

■ 手動で揃えるもの

  js/pjsk-engine.js     ↔ PjskEngine.swift
  js/calculators.js     ↔ Fmt.swift（画面ごと）
  css/style.css         ↔ MiraiKissaTheme.swift（UIデザイン仕様.md 参照）
  index.html の tmpl    ↔ MiraiAppUI.swift

■ アプリ Cursor への依頼

  docs/Web同期/Cursorアプリ用プロンプト例.txt をコピーして使う。

■ 設定

  sync/sync-config.local.json（git 非公開・パス設定済み）
  sync/機能対応表.json … 機能ごとの Web/App 対応
