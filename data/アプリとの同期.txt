未来喫茶 — プロセカアプリ（別 Cursor プロジェクト）との同期
============================================================

■ 考え方
  - 計算ロジック・マスターデータは「1か所を正」にして、もう一方へコピーする
  - 未来喫茶（このフォルダ）… GitHub Pages 用 Web
  - プロセカアプリ … 別 Cursor ワークスペース（Flutter / Web など）

■ 共有するファイル（sync/manifest.json）
  - js/pjsk-engine.js      … 計算エンジン
  - data/計算式.txt        … 式の仕様メモ
  - data/炊き数倍率.txt
  - data/楽曲基礎点.txt
  - data/楽曲基礎点.json

  Web 専用（同期しない）:
  - index.html, css/, 管理者, アナリティクス, admin.html など

■ 初回セットアップ
  1. cp sync/sync-config.example.json sync/sync-config.local.json
  2. sync-config.local.json の appProjectPath を
     プロセカアプリのフォルダの絶対パスに変更
  3. pathMap … アプリ側でパスが違うときだけ書き換え（同じならそのまま）

■ 日常の使い方（未来喫茶フォルダで）

  Web で式やデータを直した → アプリへ:
    python3 tools/sync-with-app.py push

  アプリ側で直した → Web へ:
    python3 tools/sync-with-app.py pull
    python3 tools/build-song-kiso-data.py   # 楽曲基礎点.txt を変えたとき
    git add … && git push                   # 公開する場合

  どちらが新しいか確認:
    python3 tools/sync-with-app.py diff

  試しにコピーせず一覧だけ:
    python3 tools/sync-with-app.py push --dry-run

■ おすすめの運用
  - 計算式を変えるときは、まず data/計算式.txt に書く
  - js/pjsk-engine.js を片方で直したら、すぐ push または pull
  - 公開サイトを更新するときは、同期後に未来喫茶で git push

■ sync-config.local.json は git に含めません（パスが PC ごとに違うため）
